Table Name: LB
Label : Laboratory Test Results
Description : In the SDTM Laboratory Test (LB) dataset, each record represents the result of a specific laboratory test performed for a subject at a particular time point. The variable LBTEST identifies the name of the test performed, such as Hemoglobin, ALT, or Glucose, while LBCAT and LBSCAT organize the test into hierarchical categories — with LBCAT representing the broad category (for example, Chemistry, Hematology, or Urinalysis) and LBSCAT providing a finer subcategory within it (such as Electrolytes under Chemistry). The actual test result is captured in two forms: LBSTRESC stores the standardized result as a character value, which can be either numeric or textual (for example, “Positive” or “120”), and LBSTRESN provides the same result in numeric format when applicable, allowing for quantitative analysis. The units corresponding to the numeric result are defined in LBSTRESU, ensuring that results are interpretable and comparable across datasets (for example, mg/dL or mmol/L). The normal reference range for each test result is defined by LBSTNRLO (lower limit of normal) and LBSTNRHI (upper limit of normal), both expressed in the same units as LBSTRESU. Finally, LBNRIND provides a categorical interpretation of the result in relation to these reference limits — typically indicating whether the value is Low, Normal, or High. Together, these variables define the nature of the laboratory test, classify it by category, capture the measured result in both character and numeric formats, describe its units and reference range, and interpret its clinical significance within that range.

  Data Type: TEXT
  Sample Data: DS8201-A-U201
  Description: Unique identifier for a study.

Column Name: DOMAIN
  Data Type: TEXT
  Sample Data: TA
  Description: Two-character abbreviation for the domain.

Column Name: ARMCD
  Data Type: TEXT
  Unique Values: 3
  Sample Data: TRT1, TRT2, TRT3
  Description: ARMCD is limited to 20 characters and does not have special character restrictions. The maximum length of ARMCD is longer than that for other "short" variables to accommodate the kind of values that are likely to be needed for crossover trials. For example, if ARMCD values for a 7-period crossover were constructed using 2-character abbreviations for each treatment and separating hyphens, the length of ARMCD values would be 20. 

Column Name: ARM
  Data Type: TEXT
  Unique Values: 3
  Sample Data: 5.4 mg/kg, 6.4 mg/kg, 7.4 mg/kg
  Description: Name given to an arm or treatment group.

Column Name: ETCD
  Data Type: TEXT
  Unique Values: 5
  Sample Data: PRESCRN, SCRN, TRT, ...
  Description: ETCD (the companion to ELEMENT) is limited to 8 characters and does not have special character restrictions. These values should be short for ease of use in programming, but it is not expected that ETCD will need to serve as a variable name.

Column Name: ELEMENT
  Data Type: TEXT
  Unique Values: 5
  Sample Data: Pre-Screening, Screening, Treatment, ...
  Description: The name of the element. The same element may occur more than once within an arm.

Column Name: TABRANCH
  Data Type: TEXT
  Unique Values: 2
  Sample Data: Randomized to Treatment, Assigned to Treatment
  Description: Condition subject met, at a "branch" in the trial design at the end of this element, to be included in this arm (e.g., "Randomization to DRUG X").

Column Name: TATRANS
  Data Type: TEXT
  Sample Data: If treatment is delayed >4 weeks from the planned date of dosing,the subject will be withdrawn from the study.
  Description: If the trial design allows a subject to transition to an element other than the next element in sequence, then the conditions for transitioning to those other elements, and the alternative element sequences, are specified in this rule (e.g., "Responders go to washout").

Column Name: EPOCH
  Data Type: TEXT
  Unique Values: 5
  Sample Data: PRE-SCREENING, SCREENING, TREATMENT, ...
  Description: Name of the trial epoch with which this element of the arm is associated.

Column Name: created_at

Label : Tumor Response
Description : Contains records of tumor lesion evaluations performed for each subject at each assessment time point. It includes information about target and non-target lesion responses, measurements, and evaluation results based on tumor assessment criteria (e.g., RECIST).
================================================================================
Total Columns: 23

  Data Type: TEXT
  Sample Data: DS8201-A-U201
  Description: Unique identifier for a study.

  Data Type: NUMERIC
  Sample Data: 1.0, 2.0, 3.0, ...
  Description: Sequence number given to ensure uniqueness within a dataset for a subject. May be any valid number. 

Column Name: TRGRPID
  Data Type: TEXT
  Unique Values: 26
  Sample Data: NT01, T01, TARGET, NON-TARGET, NEW, ...
  Description: TRGRPID identifies the tumor/lesion group or individual lesion within a subject’s tumor assessment records.
    It combines a group type prefix with a number sequence to show both category and lesion number:
    T01–T06 → Target Lesions (e.g., T01 = first target lesion, T02 = second target lesion)
    NT01–NT10 → Non-Target Lesions (e.g., NT01 = first non-target lesion, NT02 = second non-target lesion)
    NEW01–NEW08 → New Lesions identified after baseline
    TARGET / NON-TARGET / NEW → summary-level groups linking all lesions of that category

Column Name: TRLNKID
  Data Type: TEXT
  Unique Values: 24
  Sample Data: T01, NT01, NEW01, ...
  Description: TRLNKID is the unique lesion ID that connects this record to its definition in the TU (Tumor Identification) domain.
    Each value corresponds to a specific lesion, where:
      Txx refers to a Target Lesion
      NTxx refers to a Non-Target Lesion
      NEWxx refers to a New Lesion detected later


Column Name: TRLNKGRP
  Data Type: TEXT
  Unique Values: 3
  Sample Data: NON-TARGET, TARGET, NEW
  Description: TRLNKGRP classifies each lesion or group of lesions by their category of assessment in the tumor response evaluation:
    TARGET → measurable lesions that are quantitatively tracked
    NON-TARGET → non-measurable but clinically relevant lesions
    NEW → new lesions appearing during or after treatment
    This variable is used to link all measurement and assessment records that contribute to the subject’s overall response result in the RS (Response) domain.

Column Name: TRTESTCD
  Data Type: TEXT
  Unique Values: 9
  Sample Data: PCBSD, PCNSD, SUMDIAM, TUMSTATE, DIAM, LDIAM, PCHGBL, PCHGNAD, SAXIS
  Description: TRTESTCD is a short, standardized code used to represent the type of tumor assessment or measurement being performed. It acts as an abbreviated variable name for the tumor evaluation test captured in TRTEST.
  Example:
      PCBSD:	Percent Change Baseline in Sum of Diam
      PCNSD:	Percent Change Nadir in Sum of Diam
      SUMDIAM:	Sum of Diameter
      TUMSTATE:	Tumor State
      DIAM:	Reference Diameter
      LDIAM:	Longest Diameter
      PCHGBL:	Percent Change From Baseline
      PCHGNAD:	Percent Change From Nadir
      SAXIS:	Short Axis


Column Name: TRTEST
  Data Type: TEXT
  Unique Values: 9
  Sample Data: Percent Change Baseline in Sum of Diam, Percent Change Nadir in Sum of Diam, Sum of Diameter, ...
  Description: TRTEST provides the full descriptive name of the tumor test or measurement, corresponding to the coded value in TRTESTCD.
